# Data Architecture for AI — Notes Overview (⭐⭐⭐)

Core Data Architecture Concepts:
- Data lakes (raw, unstructured storage)
- Data warehouses (structured, analytics-ready)
- Lakehouse architecture (Delta Lake, Apache Iceberg)
- ETL vs ELT pipelines
- Streaming data (Kafka, Kinesis)
- CDC (Change Data Capture)
- Data pipelines for AI training and RAG ingestion
- Data quality and validation
- Metadata management
- Data lineage (track data origin and transformations)
- Feature stores (ML feature serving)
- Vector stores
- Knowledge graphs

Unstructured Data Pipeline (critical for RAG):
PDF / Word / Email / Image / Audio / Video
→ Document Processing
→ Extraction (OCR, parsing)
→ Chunking
→ Embedding
→ Vector Store / Knowledge Graph
→ RAG

Document types to handle:
- PDF (text extraction, table extraction)
- Word / DOCX
- Email (threading, attachments)
- Images (OCR, vision models)
- Audio (speech-to-text → text pipeline)
- Video (keyframe extraction, transcription)

Tools and frameworks:
- Apache Kafka (event streaming)
- Apache Spark (large-scale data processing)
- dbt (data transformation)
- Airflow / Prefect (pipeline orchestration)
- LangChain document loaders
- Unstructured.io (document parsing)
- AWS Glue, S3, Athena

Fintech data considerations:
- PII handling in data pipelines
- Data masking before embedding
- Regulatory data retention requirements
- Immutable audit trails
