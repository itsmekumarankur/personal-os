# AI Security — Notes Overview (⭐⭐⭐)

OWASP Top 10 for LLM / GenAI Applications:
- Prompt injection (direct)
- Indirect prompt injection (via retrieved content, tools, external data)
- Jailbreaking techniques and mitigations
- Data leakage / sensitive information disclosure
- Insecure output handling (XSS, code injection via LLM output)
- Excessive agency (agent doing too much autonomously)
- Tool abuse (LLM calling tools it shouldn't)
- Model denial of service
- Supply-chain risks (model weights, datasets, plugins)
- RAG poisoning / vector DB poisoning

Enterprise Security Controls:
- IAM (Identity and Access Management) for AI systems
- RBAC (Role-Based Access Control)
- ABAC (Attribute-Based Access Control)
- Encryption at rest and in transit
- PII detection and protection
- Data masking strategies
- Secrets management (API keys, model credentials)
- Tenant isolation in multi-tenant AI platforms
- Audit logging for all AI interactions
- Data residency and sovereignty
- Model access control

RAG-specific security:
- Vector DB access control
- Chunk-level permissions
- Preventing cross-tenant data leakage in shared RAG

Agent-specific security:
- Limiting tool permissions
- Sandboxing code execution agents
- Human-in-the-loop for high-risk actions
- Output validation before acting on LLM response

Fintech-specific: Security is a major differentiator — know it well.
