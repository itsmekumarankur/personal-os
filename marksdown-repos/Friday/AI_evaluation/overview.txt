# AI Evaluation — Notes Overview (⭐⭐⭐)

Core question to answer: "How do you know your AI system actually works?"

Traditional ML Metrics:
- Precision
- Recall
- F1 score
- Accuracy
- ROC-AUC

LLM / RAG-Specific Metrics:
- Faithfulness — does the answer stick to the retrieved context?
- Groundedness — is the answer grounded in source documents?
- Relevance — is the retrieved context relevant to the query?
- Context precision — how precise is the retrieved context?
- Context recall — was all relevant context retrieved?
- Answer relevance — does the answer address the question?
- Hallucination rate

Evaluation Methods:
- Human evaluation (gold standard but expensive)
- LLM-as-a-judge (scalable automated evaluation)
- Golden datasets / benchmark datasets
- Regression testing (did a change break something?)
- Automated evaluation pipelines
- Red teaming (adversarial testing)
- A/B testing between model versions
- Canary evaluation (new model on subset of traffic)

Evaluation Tools:
- Ragas (RAG evaluation framework)
- LangSmith (tracing + evaluation)
- Arize Phoenix (LLM observability + evaluation)
- MLflow (experiment tracking)
- Weights & Biases (experiment tracking + evaluation)

RAG Evaluation Pipeline:
- Evaluate retrieval quality separately from generation quality
- Measure end-to-end pipeline vs component-by-component
- Build automated eval into CI/CD for prompt changes

Key insight: Evaluation is often overlooked — being strong here is a differentiator.
