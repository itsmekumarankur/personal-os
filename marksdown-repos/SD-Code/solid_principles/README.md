# SOLID Principles - Simple Python Examples

Each file shows a BAD version and a GOOD version of the same idea. No dependencies, Python 3.8+.

| File | Principle | One-line idea |
|---|---|---|
| `1_srp_single_responsibility.py` | Single Responsibility | One class, one reason to change |
| `2_ocp_open_closed.py` | Open/Closed | Extend by adding code, not editing old code |
| `3_lsp_liskov_substitution.py` | Liskov Substitution | Subclasses must work wherever the parent is expected |
| `4_isp_interface_segregation.py` | Interface Segregation | Many small interfaces beat one fat one |
| `5_dip_dependency_inversion.py` | Dependency Inversion | Depend on abstractions, inject implementations |

## Run

```
python 1_srp_single_responsibility.py
python 2_ocp_open_closed.py
python 3_lsp_liskov_substitution.py
python 4_isp_interface_segregation.py
python 5_dip_dependency_inversion.py
```
