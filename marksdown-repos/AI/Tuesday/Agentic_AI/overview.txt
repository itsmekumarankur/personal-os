# Agentic AI — Notes Overview (⭐⭐⭐)

Agent Flow:
User → Agent → Planner → Tools (API / Database / Search / RAG / Code / Other Agents)
→ Observation → Next Action → Final Response

Core Topics:
- AI agents — what they are and when to use them
- Tool calling and function calling
- Planning strategies
- Memory types (short-term, long-term, semantic, episodic)
- State management across agent loops
- Agent loops and termination conditions
- Human-in-the-loop design
- Multi-agent systems
- Agent orchestration patterns
- Agent communication protocols
- Workflow vs agent (deterministic vs autonomous)
- Agent failure handling and recovery
- Agent observability and tracing

Frameworks to know:
- LangGraph (understand deeply — most important for architecture)
- LangChain
- Semantic Kernel
- LlamaIndex

Agent Patterns:
- Supervisor / orchestrator pattern
- Parallel agents
- Sequential agents
- Handoff pattern
- ReAct (Reasoning + Acting)
- Reflection pattern
- Planning pattern

Important architect skill: Know WHEN NOT to use an agent (deterministic workflow may be better).
