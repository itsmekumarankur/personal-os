# Multimodal AI — Notes Overview

Modality types:
- Text
- Image
- Audio
- Video
- Documents (PDFs, presentations)

Core concepts:
- Vision-language models (VLMs) — e.g., GPT-4V, Claude 3, Gemini
- Speech-to-text (Whisper, AWS Transcribe)
- Text-to-speech (ElevenLabs, AWS Polly)
- Document intelligence (layout-aware parsing)
- OCR (Optical Character Recognition)
- Vision-based agents (agents that can see the screen)

Model examples by modality:
- Image understanding: GPT-4o, Claude 3.5, Gemini 1.5
- Image generation: DALL-E, Stable Diffusion, Midjourney
- Speech-to-text: Whisper, Deepgram
- Text-to-speech: ElevenLabs, Amazon Polly
- Video understanding: Gemini 1.5 Pro, GPT-4o

Real-world use case pipelines:
- Invoice → Vision Model → Extraction → Validation → ERP
- Call recording → Speech-to-text → LLM → Summary → CRM
- Document image → OCR + Layout analysis → RAG pipeline
- Screenshot → Vision agent → UI automation

Multimodal RAG:
- Embedding images alongside text
- ColPali — vision-based document retrieval (no OCR needed)
- Multi-vector retrieval for mixed content

Architecture considerations:
- Latency of multimodal vs text-only models
- Cost increase for image/audio tokens
- Preprocessing pipelines for different modalities
- Fallback strategies when vision models fail
