# LLMOps / MLOps — Notes Overview (⭐⭐⭐)

LLM Lifecycle:
Data → Experiment → Model → Evaluation → Deployment → Monitoring → Feedback → Improvement

Core Topics:
- Model registry (versioning and lineage)
- Dataset versioning
- Prompt versioning (treat prompts like code)
- Evaluation datasets management
- Automated evaluation pipelines
- Model deployment strategies

Deployment Strategies:
- Canary deployment (gradual rollout)
- A/B testing (compare model versions)
- Blue/green deployment
- Shadow mode (run new model in parallel without serving)

Monitoring:
- Prompt monitoring (detect prompt drift, injection attempts)
- Cost monitoring (token usage, spend per feature)
- Token monitoring (input/output token counts)
- Latency monitoring (p50, p95, p99)
- Quality monitoring (faithfulness, hallucination rate)
- Model drift detection
- Data drift detection

Observability Stack:
Request → Prompt → Retriever → Vector DB → LLM → Tool → Response

Track at each step:
- Latency
- Token usage and cost
- Model response content
- Retrieval quality
- Errors and failures
- Hallucinations
- Tool call failures
- Agent loop counts

Tools:
- OpenTelemetry (instrumentation standard)
- Distributed tracing
- LangSmith
- Arize Phoenix
- Datadog (AI observability)
- Grafana + Prometheus
- MLflow
- Weights & Biases

Advantage: Existing distributed systems and observability experience maps directly here.
