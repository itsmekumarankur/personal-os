# AI System Design — Notes Overview (⭐⭐⭐)

Practice designing these systems end-to-end:

Beginner:
- Chatbot
- Document Q&A
- RAG system
- AI-powered search

Intermediate:
- Enterprise knowledge assistant
- Customer-support copilot
- AI coding assistant
- Document processing platform
- Meeting intelligence system

Advanced:
- Enterprise AI platform
- Multi-agent system
- AI Gateway
- LLM serving platform
- 10,000-user GenAI platform
- Multi-tenant AI platform
- Financial AI advisor
- AI fraud detection platform
- AI underwriting platform

Enterprise AI Platform Architecture:
Users → API Gateway → AI Orchestrator → [RAG / Agents / Tools]
→ [Vector DB / LLM / Enterprise APIs] → Response

Design Patterns to know:
- RAG pattern
- Agent pattern
- Router pattern
- Supervisor pattern
- Tool calling
- Prompt chaining
- Parallelization
- Reflection
- Human-in-the-loop
- Model routing
- Semantic caching
- Context compression
- Retrieval + reranking
- Multi-agent orchestration
- Event-driven AI
- Batch inference

Business / Architect thinking for design questions:
- What business problem are we solving?
- Does this actually require an LLM?
- RAG, fine-tuning, traditional ML, or deterministic workflow?
- What happens at 1M requests/day?
- What's the cost per transaction?
- What happens if the model is wrong?
- What data is allowed into the model?
- How do we detect degradation?
- How do we measure ROI?
