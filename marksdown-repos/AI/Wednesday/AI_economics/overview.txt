# AI Economics — Notes Overview (⭐⭐⭐)

Core question: "Is this AI solution economically viable?"

Cost Components:
- Model inference (tokens × price/token)
- GPU costs (self-hosted)
- Vector DB storage and query costs
- Storage (S3, object store)
- Network egress
- Data processing (chunking, embedding)
- Observability and logging
- Engineering and maintenance

Token Pricing:
- Input token pricing vs output token pricing
- Output tokens are typically 3–5× more expensive than input
- Cost differences across models (GPT-4o vs Claude vs Llama)
- Context window cost implications (longer context = higher cost)

Cost Optimization Strategies:
- Prompt caching (reuse repeated system prompts)
- Semantic caching (cache similar queries and responses)
- Model routing (use small model for simple tasks, large for complex)
- Batch inference (async, much cheaper than real-time)
- Quantization (INT8/INT4 reduces GPU memory and cost)
- Self-hosted vs managed API break-even analysis
- RAG reduces generation cost (shorter context needed)

Cost Modeling Exercise:
- Build a cost model for 1M / 10M / 100M requests
- Factor in: tokens per request, cache hit rate, model tier, infra

Build vs Buy analysis:
- When to use Bedrock/OpenAI API vs self-host
- Break-even point for self-hosting based on request volume
- Hidden costs: ops, scaling, model upgrades

Senior architect skill: Be able to walk into a business conversation and estimate AI costs before building.
