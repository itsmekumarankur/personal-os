# RAG (Retrieval-Augmented Generation) — Notes Overview (⭐⭐⭐ Extremely Important)

RAG Pipeline:
Documents → Parsing → Chunking → Embedding → Vector DB → Retriever → Reranker → LLM → Response

Topics to cover:
- Document ingestion strategies
- Chunking strategies (fixed, overlapping, semantic)
- Embeddings and vector similarity
- Cosine similarity
- Approximate Nearest Neighbor (ANN)
- Metadata filtering
- Hybrid search (dense + sparse)
- BM25 for sparse retrieval
- Reranking techniques
- Query rewriting
- Multi-query retrieval
- Parent-child retrieval
- Context compression
- Citation and grounding
- RAG evaluation metrics

Vector Databases — architecture and trade-offs:
- Pinecone
- Milvus
- Weaviate
- Qdrant
- pgvector
- OpenSearch
- Elasticsearch

Advanced RAG patterns:
- HyDE (Hypothetical Document Embeddings)
- Corrective RAG
- Self-RAG
- Agentic RAG

Goal: Be very comfortable designing end-to-end RAG systems for enterprise use cases.
