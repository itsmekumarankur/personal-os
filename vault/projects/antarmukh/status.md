# Antarmukh — Project Status

## What This Is

A personal spiritual web presence. "Antarmukh" means "inward-facing" in Sanskrit — reflecting the practice of looking within. Contains interactive study materials on classical Indian philosophy and spiritual texts.

**Location:** `projects/antarmukh/`

## Contents

- **index.html** — Main entry point
- **isha-journey.html** — Personal journey documentation
- **mandukya.html** — Study of Mandukya Upanishad (one of the shortest and most profound Upanishads, dealing with the nature of consciousness and OM)
- **yoga-sutras.html** — Study of Patanjali's Yoga Sutras

## Technical Details

- Static HTML site
- Published to GitHub Pages (CNAME present)
- Git repository with active history

## What This Reflects

The balance between outer learning (architect-kit) and inner development. The Mandukya Upanishad and Yoga Sutras are not casual choices — they represent serious engagement with the philosophy of consciousness and the science of the mind.
