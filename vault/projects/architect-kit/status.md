# Architect Kit — Project Status

## What This Is

A personal system design study lab. Contains interactive HTML learning tools covering advanced distributed systems, database design, Kafka, load balancers, and other architecture patterns. Built with audio-sync capability for synchronized note-taking.

**Location:** `projects/architect-kit/advanced-architects-lab/`

## Contents

### Advanced Architects Lab
- **Distributed Transactions** — 2PC, Saga, idempotency, eventual consistency
- **Database Design** — SQL deep dive, NoSQL patterns, indexes deep dive
- **Kafka System Design** — Build your own Kafka design
- **Load Balancer Design** — Request lifecycle, build your own LB
- **Sidecar Service Mesh** — Envoy, sidecar pattern
- **Distributed Tracing** — Build your own tracing system
- **Logical Designs** — Job scheduler, log-structured storage, OAuth2, Phoenix DR, social network, SQS queue, SQL engine, reconciliation system
