# Fintech & Wealth Platform — Domain Knowledge Index

This is professional domain knowledge, not just academic learning. This is the domain you work in.

## The Platform: Optimus

A wealth management platform. Core systems:
- **Optimus** — The platform itself (order routing, wealth services, customer-facing)
- **WinSoft** — MF order processing system
- **Valuefy** — Portfolio and holdings management
