# LLM Engineering, RAG & AI Agents Bootcamp

14-day structured bootcamp. Covers the full stack from closed-source API usage to fine-tuning open-source models to building multi-agent systems.

## Structure

### Closed Source LLMs (Days 0-4)
- Day 0: Welcome, bootcamp overview
- Day 1: Intro + character chatbot (GPT/Claude API basics, system messages)
- Day 2: Calorie tracker — practical app with structured prompts
- Day 3: AI tutor with Gradio — building UI around LLM calls
- Day 4: Benchmarking LLMs — evaluation methodology, comparing models on tasks

### Open Source LLMs (Days 5-9)
- Day 5: Open-source LLMs — HuggingFace, loading models locally
- Day 6: Reasoning models + LLM selection — when to use which model
- Day 7: RAG with LangChain — retrieval pipeline, vector stores, chunking
- Day 8: AI resume assistant — end-to-end RAG application
- Day 9: Fine-tuning with LoRA/PEFT — Gemma 3-1B on financial sentiment

### Agentic AI (Days 10-14)
- Day 10: AutoGen multi-agent teams — multi-model, GroupChat, human-in-loop
- Day 11: LangGraph — agentic workflows as directed graphs
- Day 12: CrewAI — role-based crews, data science automation
- Day 13: n8n — no-code agentic workflows
- Day 14: MCP — Model Context Protocol, AI Tutor agent with SDK
