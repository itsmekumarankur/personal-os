🤖 Multi-Agent vs Claude Code practice · Apple dashboard vs WealthPath

0. What is this file showing?

expand ▾

Yes. This file is showing two different ways of asking Claude to build a website: one through Claude's browser and one through Claude Code.

The easiest way to understand what is happening is this:

TWO APPROACHES │ ┌───────────┴───────────┐ │ │ ▼ ▼ CLAUDE BROWSER CLAUDE CODE │ │ ▼ ▼ Apple dashboard WealthPath website │ │ ▼ ▼ Multiple AI agents Coding agent work together builds the page

1. First prompt — Claude Browser

expand ▾

The first prompt tells Claude:

"You are a team of AI agents. Build an Apple investment dashboard."

So instead of asking one AI to do everything, we are creating different roles.

CLAUDE │ ┌───────────┼───────────┐ │ │ │ ▼ ▼ ▼ Research Analyst Developer Agent Agent Agent │ │ │ ▼ ▼ ▼ Find data Analyze Build UI │ │ │ └───────────┼───────────┘ ▼ Apple Dashboard

This is the key concept of the first prompt.

2. Research Agent

expand ▾

The Research Agent's job is:

Go and collect the facts.

It goes to Yahoo Finance and gets:

RESEARCH AGENT │ ▼ Yahoo Finance │ ┌───────────┼───────────┐ ▼ ▼ ▼ Price Market Cap P/E │ ├── % Change │ └── Recent trend

Then it looks at only 3 recent news articles.

NEWS │ ┌──────┼──────┐ ▼ ▼ ▼ Article Article Article 1 2 3 │ │ │ ▼ ▼ ▼ Summary Summary Summary

Why "only 3"?

Because the prompt is trying to prevent the agent from opening lots of tabs and getting distracted.

NO: Yahoo → 20 articles → 10 tabs → lots of noise YES: Yahoo → 3 articles → useful information

3. Analyst Agent

expand ▾

Now another agent takes the research and asks:

"So what does this information actually mean?"

This is different from simply collecting data.

Research Agent │ │ Facts ▼ Analyst Agent │ ▼ "What is actually important?"

It identifies:

ANALYST │ ┌────────┼────────┐ ▼ ▼ ▼ Drivers Signal Noise │ │ │ ▼ ▼ ▼ Why stock Important Ignore moved information distractions

Then it produces:

3–5 Insights + 1–2 Risks + Final stance │ ┌───┼────────┐ ▼ ▼ ▼ Bullish Bearish Neutral

And it adds confidence:

Recommendation │ ├── Bullish │ └── Confidence: 80%

So:

Research Agent = What happened?

Analyst Agent = What does it mean?

4. Developer Agent

expand ▾

Now the third agent takes all that information and builds the website.

Research Agent ──┐ │ Analyst Agent ───┼──► Developer Agent │ ▼ Build HTML

The Developer Agent creates:

APPLE DASHBOARD │ ┌────────────┼────────────┐ ▼ ▼ ▼ Apple Stats Chart News │ │ │ ▼ ▼ ▼ Price Movement Articles P/E Trend Summary Market Cap

And:

Insights │ ├── Signal ├── Noise ├── Risks └── Recommendation

The final result is:

Research + Analysis + Development ↓ apple dashboard.html

5. Why call them "Agents"?

expand ▾

Very simply:

Agent = AI given a specific job

For example:

Research Agent ↓ "I collect information." Analyst Agent ↓ "I interpret information." Developer Agent ↓ "I build the website."

Instead of:

One AI │ ├── Research ├── Analyze ├── Design └── Code

you are conceptually doing:

AI TEAM │ ┌──────────┼──────────┐ ▼ ▼ ▼ Research Analyst Developer

That's the multi-agent concept being demonstrated.

6. Now the second prompt — Claude Code

expand ▾

The second prompt is completely different.

Here you are telling Claude Code:

"Build me a WealthPath website."

There isn't a Research Agent + Analyst Agent + Developer Agent.

Instead:

CLAUDE CODE │ ▼ Understand request │ ▼ Write code │ ▼ wealthpath.html

7. What is WealthPath?

expand ▾

The prompt defines a fictional fintech product:

WEALTHPATH │ ▼ "Clarity and control over your financial future"

The website helps a customer understand their finances.

8. Step-by-step financial intake

expand ▾

Instead of showing a giant form:

BAD / LONG FORM Income ______ Expenses _____ Savings ______ Goal _________ Name __________ Email _________ Time __________ Notes _________

the prompt asks for:

FINANCIAL INTAKE │ ▼ Monthly income? │ ▼ Monthly expenses? │ ▼ Savings? │ ▼ Goal? │ ┌─────────┼─────────┐ ▼ ▼ ▼ Save more Debt Invest ...

So the user gets one question at a time.

9. Then Claude calculates financial health

expand ▾

The inputs are:

Income + Expenses + Savings + Goal

Claude Code is instructed to calculate:

FINANCIAL DATA │ ▼ Savings Rate │ ▼ Financial Health │ ┌─────────┼─────────┐ ▼ ▼ ▼ Poor Average Strong

And then give recommendations:

USER ANSWERS │ ▼ Calculations │ ▼ Personalized advice ┌─────┼─────┐ ▼ ▼ ▼ Advice Advice Advice

10. Then it creates the dashboard

expand ▾

The website shows:

DASHBOARD │ ┌──────────┴──────────┐ ▼ ▼ Income vs Expenses Savings Rate │ │ ▼ ▼ ████████ 25% ████

So the user doesn't have to interpret raw numbers.

The website visualizes them.

11. Then it adds booking

expand ▾

Finally:

BOOK CONSULTATION │ ┌──────────┼──────────┐ ▼ ▼ ▼ Name Email Time │ ▼ Notes

So the whole website becomes:

WEALTHPATH │ ▼ Financial Intake │ ▼ Calculations │ ▼ Financial Dashboard │ ▼ Recommendations │ ▼ Book Consultation

12. The BIG difference between the two prompts

expand ▾

This is probably the most important thing to understand.

First prompt

You are demonstrating multi-agent architecture:

PROBLEM │ ┌───────────┼───────────┐ ▼ ▼ ▼ Research Analyze Build Agent Agent Agent │ │ │ └───────────┼───────────┘ ▼ Final UI

Second prompt

You are demonstrating Claude Code as a coding agent:

REQUIREMENT │ ▼ CLAUDE CODE │ ┌───────┼────────┐ ▼ ▼ ▼ Analyze Code Test │ │ │ └───────┼────────┘ ▼ wealthpath.html

13. One very simple analogy

expand ▾

Imagine you're building a restaurant.

Multi-agent approach

Restaurant Project │ ┌─────┼──────┐ ▼ ▼ ▼ Chef Manager Designer │ │ │ Food Business Interior

Each person has a specialized job.

Claude Code approach

Restaurant Project │ ▼ One capable AI developer │ ┌─────┼─────┐ ▼ ▼ ▼ Plan Build Test │ ▼ Restaurant
