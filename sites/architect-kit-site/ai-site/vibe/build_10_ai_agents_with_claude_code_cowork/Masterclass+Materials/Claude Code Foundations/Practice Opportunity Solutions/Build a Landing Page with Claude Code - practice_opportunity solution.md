# Practice Opportunity — Build Your Own Landing Page

Now it's your turn. Build a landing page — first without the skill, then with it.

---

## Mindful Paws — Premium Pet Grooming

Build a landing page for a boutique pet grooming salon that includes:
- A hero section with the name "Mindful Paws" and tagline "Where grooming meets calm"
- An interactive booking quiz: Pet type (Dog/Cat/Other) → Size (Small/Medium/Large) → Service (Bath & Brush, Full Groom, Spa Day) → shows a price estimate
- A services section with 4 services, each with a description and price
- A gallery section with image placeholders of happy pets
- A booking form with pet name, owner name, phone, preferred date


## The Challenge

1. **Build it raw** — no skill, just one prompt. Save as `[business_name].html`
2. **Rebuild with skill** — same prompt, frontend-design skill active. Save as `[business_name]_v2.html`
3. **Compare** — open both side by side. What changed?

Write your own Claude Code prompt following the CIIO format (Context, Instruction, Input, Output).

---

## Solution (No skill is required):

```
Context: Building a single HTML file landing page for a pet grooming business. No frameworks, no dependencies. Don't use frontend design skill. 

Instruction: Create a single HTML file called "mindful_paws.html" for a boutique pet grooming salon called "Mindful Paws". Include a hero section with the tagline "Where grooming meets calm", an interactive booking quiz that asks 3 questions one at a time (pet type, size, service) and shows a price estimate, a services section with 4 services and prices, a gallery section with image placeholders, and a booking form with pet name, owner name, phone, and preferred date. Make it fully functional with smooth transitions.

Input:
- Business: Mindful Paws
- Tagline: "Where grooming meets calm"
- Services: Bath & Brush ($45), Full Groom ($75), Spa Day ($120), Puppy First Groom ($55)

Output: A single self-contained HTML file I can open in any browser. File name: mindful_paws.html
```
