Benchmarks — the trap

Q21If Model A scores 84%, Model B scores 86%, and Model C scores 85% on a benchmark, what can you really conclude? When does a benchmark stop discriminating between models?reveal

Suppose:

Benchmark X

Model A = 84%
Model B = 86%
Model C = 85%

Looks like:

C < A < B

But if the benchmark is saturated:

100% |
     |
 90% |
     |    A B C
 85% |----*--*--*----
     |
     +----------------

There isn't much discriminative power left.

It's like comparing:

100m runner A = 9.81 sec
100m runner B = 9.82 sec

versus:

A = 15 sec
B = 30 sec

The benchmark has to separate the candidates meaningfully.
