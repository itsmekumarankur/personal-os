Q2. Why should you avoid using the AWS root user for daily work?

Show answerDockerfile = instructions/recipe → Image = packaged blueprint created from those instructions → Container = running instance of the image.
Q4. What does ECR do?
Show answerAmazon ECR (Elastic Container Registry) stores Docker/container images in AWS.

Q6. What is CloudWatch?

2. 🔐 IAM — Identity and Access Management

IAM controls who can access what in AWS and what they are allowed to do.

AWS Account
   │
   ├── Root User → maximum power
   │
   ├── IAM User → restricted working identity
   │
   └── Permissions/Policies → what the user can do

AWS IAM is highly granular. That can make it feel complicated, but it is an important production skill.

Root User

  • Extremely powerful account.
  • Should not be used for everyday work.
  • Used in this lesson for permission/user setup and billing/budget management.

IAM User

The course creates an AI engineer IAM user for normal work.

MFA

Multi-Factor Authentication adds another authentication factor, such as an authenticator-app code. The lesson stresses securing the root account with MFA.

Account ID

AWS provides a 12-digit account identifier. Keep track of it because it is used in account/IAM login workflows.

ARN

ARN = Amazon Resource Name. It uniquely identifies an AWS resource.

3. 💰 AWS Cost Awareness & Budgets

AWS is an industrial-strength cloud platform. Some resources can cost money, so monitoring spend is part of the production skill.

Important: The lesson emphasizes that AWS provides alerts, but not a simple hard spending cap that automatically shuts everything down.

Budget alerts used in the lesson

  1. Zero-spend budget: alert when spending goes above a very small amount.
  2. Monthly cost budget: alert at thresholds such as 85%, 100%, and forecasted 100%.

Practice: Keep checking Billing and Cost Management regularly instead of relying only on alerts.

4. 👥 IAM User Groups & Policies

Instead of attaching permissions individually, the lesson creates a user group and attaches policies to that group.

User Group
    │
    ├── App Runner Full Access
    ├── ECR Full Access
    ├── CloudWatch Logs Full Access
    └── IAM User Change Password
            ↓
       AI engineer

The lesson calls the group Broad AI Engineer Access.

Professional concept: Real production environments generally aim for more granular permissions—give users only the access they actually need.
5. 🌍 AWS Regions

AWS has many geographical regions. The AWS console lets you select the region you are working in.

AWS

Region names have exact formats, for example us-east-1. The lesson warns that typos can lead to confusing errors.

6. 🐳 Docker — The Core Idea

Docker provides a lightweight, isolated and portable environment for running an application.

A useful mental model from the lesson is a computer inside your computer, but much lighter than a traditional virtual machine.

Why Docker?

  • Isolation: application runs in its own environment.
  • Portability: the same packaged environment can run on different machines.
  • Reproducibility: you can recreate the same environment.

Three terms to remember

11. 🚀 Deploy with ECR + App Runner

Important App Runner settings from the lesson

  • Port: 8000
  • Auto scaling example: minimum 1, maximum 1
  • Health protocol: HTTP
  • Health path: /health
  • Timeout: 5 seconds
  • Interval: 20 seconds

App Runner can be configured with more instances when an application needs greater scalability.
