Q1. What is the difference between frontend and backend?
Show answer

Frontend runs in the user's browser and handles the UI. Backend runs on the server and handles business logic, databases, LLM/API calls, secrets and other server-side work.

Q2. How do frontend and backend normally communicate?
Show answer

The frontend makes an API request to a backend endpoint. The backend processes it and commonly returns JSON, which the frontend uses to update the UI.

Q3. What is React?
Show answer

A component-based JavaScript/TypeScript frontend framework/library approach for building user interfaces.

Q4. What does SPA mean?
Show answer

Single Page Application: the application frontend is loaded once and subsequent interaction commonly happens through API calls while the same client application updates the UI.

Q5. Why use Next.js on top of React?
Show answer

React is flexible and relatively bare-bones. Next.js adds useful application-level functionality such as routing, data fetching and rendering tools, reducing the number of separate decisions/frameworks you need to make.

Q6. What are props and state in React?
Show answer

Props are information passed from higher-level components to lower-level components. State represents information/status managed by components that can change and cause the UI to update.

Q7. Why is FastAPI being used?
Show answer

It is a modern Python framework optimized for building API servers/endpoints.

Q8. Why is the Next.js API folder removed?
Show answer

Because this project uses a separate Python FastAPI backend rather than a JavaScript/Next.js backend.

Q9. What is requirements.txt for?
Show answer

It lists the Python packages that need to be installed, such as FastAPI, Uvicorn and OpenAI.

Q10. What is the app being built on Day 2?
Show answer

A simple business idea generator that uses an LLM to generate a new business idea for AI agents.

Q11. What is the five-day progression?
Show answer

Day 2: frontend + backend. Day 3: authentication + subscription. Day 4: real business functionality. Day 5: deploy the application to AWS.

3. 🔌 How an API Call Connects Them

A typical flow is:

User interacts with UI
        ↓
Frontend makes API call
        ↓
Specific URL / endpoint
        ↓
Backend function runs
        ↓
Backend generates result
        ↓
JSON response
        ↓
Frontend receives JSON
        ↓
UI changes

An endpoint is essentially a particular URL through which backend functionality can be called.

Important: The frontend does not need to know how the backend internally generates the result. It calls the endpoint and consumes the response.
4. 📄 Another Backend Pattern — Server Generates the Whole Page

The backend is not limited to returning JSON. Another pattern is for the server to generate the entire web page and send the resulting page to the browser.

Browser requests /home
        ↓
Server generates page
        ↓
Complete page returned
        ↓
Browser displays it

The course will expose you to both patterns.

7. ⚛️ React — The Important Ideas

React is component-based. A UI is assembled from reusable building blocks.

             React UI
                 │
      ┌──────────┼──────────┐
      ▼          ▼          ▼
   Header      Form       Results
      │          │          │
  reusable   reusable   reusable
  component  component  component

Declarative UI

Instead of manually telling the browser every individual DOM operation, you describe what the UI should look like for a given state. React figures out which parts need updating when state changes.

Why this matters

Historically developers had to write lots of logic to determine which parts of the screen should change. React handles that update process for you.

9. 📝 JSX / TSX

JSX and TSX provide a convenient hybrid syntax combining markup with JavaScript/TypeScript logic.

</UI element>

The course uses TypeScript + TSX. The instructor emphasizes that it becomes natural after seeing it repeatedly.

11. ▲ Next.js — React Application Framework

Next.js is an application framework built on top of React. It packages additional functionality so developers don't have to make as many separate framework choices.

It provides things such as:

  • Rendering options
  • Transpiling/build tooling
  • Bundling

13. 🌐 Client-Side vs Server-Side Rendering

A page can ultimately be generated in two broad places:

Client-side rendering:
Server sends application code
        ↓
Browser creates the final page

Server-side rendering:
Request
  ↓
Server runs code
  ↓
Server creates final page
  ↓
Browser receives page

For this course, the instructor chooses the client-side approach because it is simpler and fits the course better.

25. ⚡ FastAPI — How the /api Route Works

A route is defined so that when a request reaches /api, a Python function runs and its result becomes the response.

30. ⭐ Critical Concepts to Really Understand

1. Full stack

Frontend and backend working together as one application.

2. API endpoint

A URL through which the frontend can call backend functionality.

3. React

Component-based way of building interactive UIs.

4. Next.js

Application framework built on React that adds routing, rendering and other development tooling.

5. FastAPI

Python framework for building API servers.

6. Tailwind

CSS framework providing utility classes for fast styling.

7. Pydantic connection

FastAPI is built around strong schema/data-description capabilities through Pydantic, which becomes especially important in later days.

8. LLM call

The backend sends a prompt to an LLM and returns the generated result.

9. Deployment mindset

A major part of production engineering is configuration and setup, not just writing application logic.
