0. What is this prompt demonstrating?

This prompt is demonstrating a data-analysis workflow using reusable Claude commands. The important idea is that you are taking one Excel file and passing it through several analysis stages.

In one picture

saas_monthly_metrics.xlsx │ ▼ /explore-data │ ▼ Understand the data │ ▼ /validate (optional) │ ▼ Check data quality │ ▼ /statistical-analysis │ ▼ Find patterns/trends │ ▼ Clean the data │ ▼ v1 file │ ┌──────────┴──────────┐ ▼ ▼ /build-dashboard /create-viz │ │ ▼ ▼ Dashboard Charts │ │ └──────────┬──────────┘ ▼ PowerPoint Deck │ ▼ Present to Manager

1. /explore-data

expand ▾

First, Claude looks at the Excel file.

Excel │ ▼ /explore-data │ ├── What columns exist? ├── How many rows? ├── What does the data mean? └── What values are present?

Think of this as:

"Claude, first understand my data."

2. /validate

expand ▾

This one is optional.

Data │ ▼ /validate │ ├── Missing values? ├── Bad values? ├── Duplicates? └── Data problems?

Think:

"Is my data trustworthy enough to analyze?"

3. /statistical-analysis

expand ▾

Now Claude actually analyzes the data.

Clean/validated data │ ▼ /statistical-analysis │ ├── Trends ├── Patterns ├── Relationships └── Important findings

Think:

"What does the data tell me?"

4. Clean the data and create v1

expand ▾

This is important:

ORIGINAL FILE │ │ DON'T MODIFY ▼ saas_monthly_metrics.xlsx ↓ Clean the data │ ▼ NEW FILE v1

The instruction specifically says don't overwrite the original.

So:

Original │ └── stays safe ✓ Cleaned version │ └── v1 ✓

This is a good data-analysis practice because you always retain the original/raw dataset.

8. The simplest way to remember it

expand ▾
EXPLORE ↓ VALIDATE ↓ ANALYZE ↓ CLEAN ↓ DASHBOARD ↓ VISUALIZE ↓ PRESENT

So this is not just "analyze an Excel file."

It is demonstrating a complete AI-powered data workflow:

RAW DATA │ ▼ UNDERSTAND │ ▼ CHECK DATA │ ▼ ANALYZE │ ▼ CLEAN / SAVE │ ▼ VISUALIZE │ ▼ DASHBOARD │ ▼ POWERPOINT │ ▼ MANAGER
And the interesting part is that commands like /explore-data, /validate, /statistical-analysis, /build-dashboard, and /create-viz are being used as reusable specialized actions, rather than you having to write a long prompt for every individual step.
