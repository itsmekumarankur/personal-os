7. What does "WITHOUT SKILL" mean?

expand ▾

Give Claude Code a normal prompt — no special frontend‑design skill activated.

You → “Build this website” → Claude Code → HTML/CSS/JS → mindful_paws.html

Claude creates the functional website with default design decisions.

8. What does "WITH SKILL" mean?

expand ▾

Same requirements, but tell Claude to use the frontend‑design skill.

You → same requirements + frontend‑design skill
↓
Claude Code → HTML + CSS + JS + better design decisions
↓
mindful_paws_v2.html

The skill influences visual/design quality (layout, typography, spacing, colors, UX, interactions) — not the business logic.

9. What is CIIO?

expand ▾

CIIO = Context · Instruction · Input · Output — a structured prompt framework.

CIIO PROMPT | +----------+----------+ | | | v v v Context Instruction Input | | | +----------+----------+ | v Output
  • C (Context): “I am building a single HTML landing page for a boutique pet grooming business.”
  • I (Instruction): “Create a landing page with Hero, Booking quiz, Services, Gallery, Booking form.”
  • I (Input): Business: Mindful Paws · tagline · services with prices.
  • O (Output): “One self‑contained HTML file, mindful_paws.html”
