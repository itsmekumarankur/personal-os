0. What are these 5 prompts building?

expand ▾

Absolutely. These 5 prompts are building one complete automated Apple-monitoring system, step by step.

The easiest way to understand them is:

PROMPT 1 ↓ Find Apple information ↓ PROMPT 2 ↓ Put information into Excel ↓ PROMPT 3 ↓ Turn information into PowerPoint ↓ PROMPT 4 ↓ Turn the whole process into ONE command ↓ PROMPT 5 ↓ Run that command automatically every 2 hours

So the overall journey is:

APPLE MONITORING SYSTEM │ ▼ ┌──────────────────────┐ │ 1. SEARCH THE WEB │ └──────────┬───────────┘ ↓ Apple data │ ▼ ┌──────────────────────┐ │ 2. CREATE EXCEL │ └──────────┬───────────┘ ↓ apple_monitor.xlsx │ ▼ ┌──────────────────────┐ │ 3. CREATE POWERPOINT│ └──────────┬───────────┘ ↓ apple_update.pptx │ ▼ ┌──────────────────────┐ │ 4. CREATE COMMAND │ └──────────┬───────────┘ ↓ /apple-monitor │ ▼ ┌──────────────────────┐ │ 5. SCHEDULE IT │ └──────────┬───────────┘ ↓ Every 2 hours

1. Prompt 1 — Search Apple information

expand ▾

The first prompt is simply saying:

"Go to the internet and find everything important about Apple right now."

It wants information from several areas:

APPLE │ ┌──────────────┼──────────────┐ ↓ ↓ ↓ STOCK ANALYSTS NEWS │ │ │ ↓ ↓ ↓ Price Buy/Sell iPhone Change Ratings AI Volume Targets Regulation P/E Upgrades Earnings Market Cap Downgrades Supply chain

It also checks social sentiment:

SOCIAL MEDIA │ ┌─────────┼─────────┐ ↓ ↓ ↓ X Reddit Forums │ │ │ └─────────┼─────────┘ ↓ What are people saying about Apple?

And it compares Apple against:

MARKET │ ┌────┴────┐ ↓ ↓ SPY QQQ │ │ └────┬────┘ ↓ Compare with AAPL

Final output of Prompt 1

PROMPT 1 │ ▼ Apple Monitor Report │ ┌─────────┼─────────┐ ↓ ↓ ↓ Price Sentiment News │ │ │ └─────────┼─────────┘ ↓ Bullish / Neutral / Bearish

So Prompt 1 = Research.

2. Prompt 2 — Put everything into Excel

expand ▾

Now Prompt 2 says:

"Take the information you just collected and organize it properly in Excel."

Notice something important:

It says:

Prompt 1 │ ▼ Apple research │ │ SAME CONVERSATION ▼ Prompt 2

So Prompt 2 doesn't need to search everything again.

It uses the result from Prompt 1.

What does it create?

It creates:

apple_monitor.xlsx

Inside:

apple_monitor.xlsx │ ├── Dashboard │ ├── Fundamentals │ ├── Sentiment │ └── News

Dashboard

Dashboard │ ├── Date / Time ├── Apple price ├── Daily change ├── Overall sentiment └── AAPL vs SPY vs QQQ │ ▼ Chart

Fundamentals

Fundamentals │ ├── Market Cap ├── P/E ├── 52-week range ├── Volume └── Other metrics

Sentiment

Sentiment │ ├── Analyst opinion ├── Buy / Hold / Sell ├── Price targets ├── Social sentiment └── Overall mood

News

News │ ├── Headline ├── Source ├── Date └── Impact │ ├── Positive ├── Negative └── Neutral

So:

Prompt 1 = collect information

Prompt 2 = organize information

3. Prompt 3 — Create PowerPoint

expand ▾

Now Prompt 3 says:

"Take the same Apple information and make a presentation."

Again:

Prompt 1 │ ▼ Research │ ▼ Prompt 2 │ ▼ Excel │ ▼ Prompt 3 │ ▼ PowerPoint

It creates:

apple_update.pptx

with 6 slides:

POWERPOINT │ ├── Slide 1 │ Apple Monitor │ ├── Slide 2 │ Price snapshot │ ├── Slide 3 │ Analyst sentiment │ ├── Slide 4 │ Social sentiment │ ├── Slide 5 │ Important news │ └── Slide 6 Overall assessment

So now you have:

APPLE DATA │ ┌────────┴────────┐ ↓ ↓ EXCEL POWERPOINT │ │ Detailed data Quick summary

Excel = detailed reference

PowerPoint = quick presentation

4. Prompt 4 — Create /apple-monitor

expand ▾

This is where the workflow becomes interesting.

Before Prompt 4:

You │ ├── Prompt 1 manually │ ├── Prompt 2 manually │ └── Prompt 3 manually

That's repetitive.

Prompt 4 says:

"Combine all three steps into one reusable command."

So:

BEFORE You │ ├── Search │ ├── Create Excel │ └── Create PowerPoint

becomes:

AFTER You │ │ ▼ /apple-monitor │ ├── Search Apple │ ├── Create Excel │ └── Create PowerPoint

That's the whole purpose of Prompt 4.

5. Think of /apple-monitor like a button

expand ▾

Instead of doing:

Step 1 ↓ Step 2 ↓ Step 3

you now have:

YOU │ ▼ /apple-monitor │ ▼ ┌───────────────┐ │ Step 1 │ │ Search Apple │ └───────┬───────┘ ↓ ┌───────────────┐ │ Step 2 │ │ Create Excel │ └───────┬───────┘ ↓ ┌───────────────┐ │ Step 3 │ │ Create PPT │ └───────────────┘

So Prompt 4 = Automation/reusability.

6. Prompt 5 — Run it automatically

expand ▾

Now the final prompt says:

"Don't make me run /apple-monitor manually. Run it every 2 hours during market hours."

Without Prompt 5:

You │ ▼ /apple-monitor │ ▼ Report

With Prompt 5:

SCHEDULE │ ▼ Every 2 hours │ ┌───────┼───────┐ ↓ ↓ ↓ 9 AM 11 AM 1 PM │ ↓ 3 PM │ ▼ /apple-monitor │ ┌───────┼────────┐ ↓ ↓ ↓ Search Excel PPT

And it doesn't run on weekends:

MON ──► Run TUE ──► Run WED ──► Run THU ──► Run FRI ──► Run SAT ──► STOP SUN ──► STOP

So Prompt 5 = Scheduling.
