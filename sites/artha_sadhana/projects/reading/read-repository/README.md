# Read Repository

A daily reading log — one article a day, committed to git.

Articles are organized into three tracks:

| Track | Folder | What goes here |
|---|---|---|
| AI | [`/ai`](./ai/) | Machine learning, LLMs, AI tools, research papers |
| Architecture | [`/architecture`](./architecture/) | System design, distributed systems, engineering patterns |
| Business & Product | [`/business-product`](./business-product/) | Product thinking, strategy, PM craft, growth |

## Article format

Each article is a Markdown file named `YYYY-MM-DD-slug.md` inside the relevant track folder.

```
ai/2026-07-06-attention-is-all-you-need.md
architecture/2026-07-07-saga-pattern-distributed-transactions.md
business-product/2026-07-08-jobs-to-be-done.md
```

### File template

```markdown
# Article Title

**Source:** [Title](URL)  
**Date read:** YYYY-MM-DD

```
