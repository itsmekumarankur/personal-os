# learning-labs

One folder per course. Each course folder has a `README.md` that answers three questions: what was built, what was kept, what would be skipped.

The notebooks are the artifacts. The README is the reflection.

## Adding a new course

1. Create a folder: `ai-courses/your-course-name/`
2. Put notebooks, code, and assets inside
3. Add a `README.md` using the template in any existing course folder
4. Add a row to the table above
