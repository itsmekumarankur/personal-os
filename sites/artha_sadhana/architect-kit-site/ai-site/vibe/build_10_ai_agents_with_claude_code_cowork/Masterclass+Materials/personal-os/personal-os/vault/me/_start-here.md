# About Me

This folder contains pages about you. The /setup command creates these
from your LinkedIn profile, posts, and self-description.

Pages the agent will create here:
- role.md - Your role, responsibilities, what you do day to day
- goals.md - Current goals and priorities
- preferences.md - Communication preferences, tools you use, habits
- journal/ - Daily reflections and notes (if you want the agent to file these)

To get started: run /setup and paste your LinkedIn About section when asked.
