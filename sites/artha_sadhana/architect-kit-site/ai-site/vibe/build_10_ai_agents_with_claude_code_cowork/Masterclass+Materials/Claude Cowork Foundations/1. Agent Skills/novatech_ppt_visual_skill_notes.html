0. What is this exercise showing?

Yes. This one is showing a 3-step experiment to understand what a Skill actually does. The files describe Prompt 1, Prompt 2, and Prompt 3.

Think of the whole process like this:

SALES DATA quarterly_sales.csv | v +----------------+ | PROMPT 1 | | NO SKILL | +----------------+ | v novatech_annual_review.pptx | | INSTALL SKILL | v +----------------+ | PROMPT 3 | | WITH SKILL | +----------------+ | v novatech_annual_review_v2.pptx | v COMPARE v1 vs v2

1. What is happening in Prompt 1?

expand ▾

First, you have a CSV file containing sales data.

quarterly_sales.csv | +-- Month +-- Quarter +-- Region +-- Product +-- Revenue +-- Units sold +-- Target

The data covers:

2025 | +-- North America +-- Europe +-- Asia Pacific | +-- Cloud Services +-- Consulting

You tell Cowork:

"Take this data and create an executive presentation."

But you explicitly say:

DO NOT USE PPT SKILLS

So:

CSV DATA | v Cowork / AI | | No presentation skill v Basic presentation | v v1.pptx

The expected result is functional, but visually basic.

For example:

+--------------------------------+ | Q1 Sales Performance | | | | • Revenue increased | | • North America performed best | | • Cloud Services grew | | • Target achievement was good | | | | [Basic Chart] | +--------------------------------+

The problem is not necessarily that the information is wrong.

The problem is how the information is presented.

2. Prompt 2 — Install the Skill

expand ▾

This is not a prompt to Cowork.

You are teaching Cowork a new capability.

The skill is called:

ppt-visual

Think of a Skill as an instruction manual / specialist knowledge.

Before: Cowork | +-- General AI knowledge | +-- Can create PPT | v Basic presentation After installing skill: Cowork | +-- General AI knowledge | +-- Can create PPT | +-- ppt-visual skill | +-- Layout +-- Typography +-- Color +-- Visual hierarchy +-- Charts +-- Whitespace +-- Storytelling | v Better presentation

The important idea is:

You are not changing the business data. You are changing the instructions/capability available to the AI for designing the output.

The instructions say to download SKILL.md, upload it under Cowork's Skills section, and verify that ppt-visual is active.

3. What is inside this Skill conceptually?

expand ▾

You don't need to think of it as magic.

Think:

ppt-visual | +-----------+-----------+ | | | v v v LAYOUT DESIGN STORY | | | v v v Split Colors One idea grids Fonts per slide spacing hierarchy emphasis

Without the skill, AI might think:

"I need to show this information."

With the skill, AI is instructed to think more like:

"What is the most important message on this slide, and how should the visual hierarchy communicate it?"

That's the core difference.

5. What changes between v1 and v2?

expand ▾

This is the actual learning objective.

v1 — Without Skill

The file says you can expect things like:

+--------------------------------+ | Sales Performance | | | | • Revenue was strong | | • Europe improved | | • Cloud Services grew | | • Target was achieved | | | | [Chart] | +--------------------------------+

Characteristics:

Bullet-heavy ↓ Default fonts ↓ Charts without much context ↓ Weak visual hierarchy ↓ Slides look similar ↓ Walls of text

v2 — With Skill

Now the same information might be organized more like:

+------------------------------------------------+ | 2025 SALES | | | | $12.4M | | ANNUAL REVENUE | | | | +-----------------------------+ | | | | | | | Revenue Trend | | | | /─────── | | | | / | | | |_____/ | | | +-----------------------------+ | | | | ↑ 18% YoY | +------------------------------------------------+

Instead of giving equal importance to everything:

Revenue Units Target Region Product Quarter ...

the slide says:

WHAT MATTERS? | v BIG NUMBER | v Supporting chart | v Explanation

6. "One clear message per slide"

expand ▾

This is one of the biggest ideas in the exercise.

Without skill:

SLIDE Revenue Units Target Region Product Quarter Growth Comments Chart Bullets

Everything is competing for your attention.

With skill:

SLIDE "Revenue exceeded target by 14%" | BIG NUMBER | supporting chart | short insight

The audience immediately understands:

What am I supposed to take away from this slide?

7. What does "hero number" mean?

expand ▾

Suppose the analysis shows:

Revenue = $12.4M

Instead of hiding it inside a bullet:

• Annual revenue reached $12.4M.

the presentation might make it the visual focus:

+--------------------------------+ | | | $12.4M | | | | 2025 Revenue | | | | ↑ 18% vs. 2024 | | | +--------------------------------+

That big number is the hero number.

8. What does "callout annotation" mean?

expand ▾

Instead of simply showing:

Revenue Trend / / / ___/________

the skill encourages something like:

Revenue Trend $12.4M * /| ↑ 18%| / | ______/ | ____/ _______/

The chart itself points out the important insight.

So the executive doesn't have to study the chart and figure it out.

9. Why do they use a NEW conversation?

OLD SESSION | +-- No ppt-visual | v v1 NEW SESSION | +-- ppt-visual ACTIVE | v v2

This makes the comparison cleaner.

11. The complete learning concept

expand ▾

The entire exercise is really teaching this:

SAME DATA | v SAME BUSINESS REQUIREMENT | +-----+-----+ | | v v NO SKILL WITH SKILL | | v v v1.pptx v2.pptx | | | | +-----+-----+ | v COMPARE | v Understand the value of a Skill

In one sentence:

A Skill gives the AI specialized instructions and expertise for a particular type of work, so the same raw request and data can produce a substantially better-designed result.
