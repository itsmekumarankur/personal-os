🔍 The Chess Analogy

   Two opponents. They seem to have nothing in common.

   Chunk UP:  "For what purpose are you playing?"
              → Both say: "To WIN."
              → AGREEMENT FOUND. Connection made.

   Chunk DOWN: "How specifically will you win?"
              → Every player has a DIFFERENT strategy.
              → That's the game. That's the fun.

Why it builds trust:

  • Chunking up finds the agreement frame – the shared purpose beneath surface conflict. This extends grace, because you see they want the same big thing.
  • Chunking down clarifies the specifics – turns vague intentions into actionable steps. Can feel like an interrogation if overdone, so use gently.

Ken's confession: Interrogators use this. He learned it in Iraq from a military interrogator. Don't underestimate two simple questions.

   From René Descartes (1600s).
   Everything has an opposite. Look at the same decision
   from FOUR angles to get complete clarity.

   THE DECISION: "Should I do this thing?"

   ┌─────────────────────────────────────────────────────┐
   │                                                     │
   │  Q1: CONVERSE                                      │
   │  "What WOULDN'T happen if you DID?"                │
   │  → Eliminates unfounded fears.                     │
   │                                                     │
   │  Q2: THEOREM                                       │
   │  "What WOULD happen if you DID?"                  │
   │  → Reveals the positive reality.                   │
   │                                                     │
   │  Q3: NON-MIRROR IMAGE REVERSE                      │
   │  "What WOULDN'T happen if you DIDN'T?"            │
   │  → The double-negative. Shows stagnation.          │
   │    Nothing changes if you do nothing.              │
   │                                                     │
   │  Q4: INVERSE                                       │
   │  "What WOULD happen if you DIDN'T?"               │
   │  → The cost of inaction. What you lose.            │
   │                                                     │
   └─────────────────────────────────────────────────────┘

🎬 Jason's Demo Snippet

   Decision: Taking leadership training ONLINE.

   Q1: What wouldn't happen if you did?
   → "I wouldn't have the impact I feel I can offer."

   Q2: What would happen if you did?
   → "Potential impact, influence, helping lives forward."

   Q3: What wouldn't happen if you didn't?
   → "People would miss out. I wouldn't move forward."

   Q4: What would happen if you didn't?
   → "I'd stay in the same place. No growth."

   Result: Complete clarity. Decision reinforced.

🚣 The 8-Step Drift (Questions)

   ┌────────────────────────────────────────────────────┐
   │                                                    │
   │ 1️⃣  What's WRONG?                                  │
   │    "Tell me about it." Listen, paraphrase.          │
   │    (They'll spill the negative.)                    │
   │                                                    │
   │ 2️⃣  What CAUSED this problem?                      │
   │    Ownership step. "What's your part?"              │
   │    Moves from external blame → internal power.      │
   │                                                    │
   │ 3️⃣  How specifically have you NOT resolved it?     │
   │    Chunk down on inaction. They see their           │
   │    own pattern.                                     │
   │                                                    │
   │ 4️⃣  How CAN you find a solution?                   │
   │    Pointing toward light. Taps resourcefulness.     │
   │    "Who can help? What skills do you have?"         │
   │                                                    │
   │ ═══════════ THE FLIP ═══════════                   │
   │                                                    │
   │ 5️⃣  What DO you want? (positive)                   │
   │    From "I don't want X" to "I WANT Y."            │
   │    Must be stated in the positive.                  │
   │                                                    │
   │ 6️⃣  When will you stop having this limitation?     │
   │    "When will you stop believing this is bigger    │
   │     than you?" They name the moment.                │
   │                                                    │
   │ 7️⃣  In HOW MANY WAYS can you resolve this?         │
   │    Creativity unleashed. List options.              │
   │    (No judgment, just possibilities.)               │
   │                                                    │
   │ 8️⃣  How do you see things DIFFERENTLY now?         │
   │    Confirms the shift.                             │
   │    "Problem" is now past tense.                     │
   │                                                    │
   └────────────────────────────────────────────────────┘

🎾 The Tennis Ball Analogy

   Life moves like a spinning tennis ball.

        TOP: Hope, Vision, Aspiration
        ╔═══════════════════╗
        ║    ☀️ HOPE       ║  ← You start here, excited.
        ╚══════╤════════════╝
               │
               ▼  (First move is often DOWN. Feels wrong.)
        ╔═══════════════════╗
   LEFT ║ PERSEVERANCE     ║ RIGHT
        ║ (Feels like      ║
        ║  going backwards) ║
        ╚══════╤════════════╝
               │
               ▼
        ╔═══════════════════╗
        ║ 🧱 CHARACTER     ║  ← Maturity kicks in.
        ╚══════╤════════════╝  You're still moving forward.
               │
               ▼
        ╔═══════════════════╗
        ║    ☀️ HOPE       ║  ← You arrive at a NEW level.
        ╚══════════════════╝    Then the cycle repeats.

   MORAL:
   ┌─────────────────────────────────────────────┐
   │  When you feel like you're going BACKWARDS, │
   │  you're actually still going FORWARDS.       │
   │                                             │
   │  The bottom of the ball moves opposite       │
   │  to the top. It's physics. It's normal.     │
   │                                             │
   │  Getting worse before you get better =      │
   │  natural progression.                       │
   └─────────────────────────────────────────────┘

  • □ HIERARCHY OF IDEAS — "For what purpose?" (up) / "How specifically?" (down). Find agreement above. Clarify steps below.
  • □ CARTESIAN COORDINATES — For decisions. 4 angles. Complete clarity. What wouldn't/would happen if you did/didn't?
  • □ PROBLEM-TO-SOLUTION DRIFT — 8 questions. Guide from negative → positive. Don't give solutions. Ask the questions. Let them own their breakthrough.
  • □ THE CHARACTER LOOP — Trials → Perseverance → Character → Hope. Feeling like you're going backwards? Good. You're on track. Keep spinning.
  • □ VOCABULARY GROWTH — Read. One book of words a year. Your words shape your world.
