Quick setup — edit config.js
Step 1 · API key

Get a free key at alphavantage.co (25 req/day, 5/min). Paste it into config.js as API_KEY. Without a key, buy-price data still shows on both pages.

Step 2 · Holdings

Edit the HOLDINGS array in config.js. Each entry needs symbol (NSE:RELIANCE or BSE:500325), name, sector, qty, buyPrice, and buyDate.
